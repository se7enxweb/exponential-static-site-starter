# site/

The code and settings of your site, copied over the Exponential installation before the build:

- `settings/override/`: `site.ini.append.php` and your other overrides (never a password: the repository is public)
- `settings/siteaccess/<name>/`: your siteaccesses
- `extension/<name>/`, `design/<name>/`: your own extensions and designs

Leave it empty to publish the default site package. This file is not copied.
